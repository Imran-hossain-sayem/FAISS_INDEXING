# 📚 Book Search with FAISS Indexing

A Streamlit dashboard demonstrating different FAISS indexing methods for semantic book search.

## Features
- 🔍 Semantic search using sentence embeddings
- 📊 Comparison of 5 FAISS indexing methods
- ⚡ Performance metrics and visualization
- 📈 Category distribution analysis
- 🎯 Precision@K and Accuracy@K metrics
